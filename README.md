# Classificador-de-Pishing
Modelo de Machine Learning que classifica e-mails como legítimos ou tentativas de phishing, a partir de características do remetente, do assunto e do conteúdo da mensagem.
## Objetivo
- Identificar automaticamente e-mails maliciosos
- Entender quais características mais indicam uma tentativa de phishing
- Praticar classificação supervisionada aplicada à segurança da informação

## Features analisadas
- Presença de links suspeitos e domínios encurtados
- Palavras de urgência no assunto ("sua conta será bloqueada")
- Inconsistência entre remetente exibido e domínio real

## Tecnologias
- Python
- Pandas / Scikit-learn
- Processamento de texto (NLP básico)

## Status
Modelo simples em desenvolvimento, com fins de estudo (curso de ADS — UNICID).

## Aviso importante
A base utilizada é *pública/fictícia* e serve apenas para aprendizado. Este
projeto tem finalidade exclusivamente defensiva e educacional.
